Materi

  

    
Alamat IP
Identitas perangkat di jaringan. IPv4 = 32 bit, ditulis 4 oktet, contoh 192.168.1.23. Subnet mask (misal 255.255.255.0 atau /24) memisahkan bagian jaringan dan bagian host.

    
Ping
Perintah untuk mengecek apakah host bisa dijangkau, memakai paket ICMP. Hasilnya menampilkan waktu balasan (ms) dan paket yang hilang.

    
Gateway & DNS
Gateway adalah pintu keluar jaringan lokal (biasanya router). DNS mengubah nama domain, misalnya google.com, menjadi alamat IP.

    
Perangkat Keras
NIC (kartu jaringan), kabel UTP + konektor RJ45, switch, router, access point, dan modem. Kabel straight untuk PC ke switch, crossover untuk perangkat sejenis.

    
Perangkat Lunak
Sistem operasi (Windows, Linux), driver NIC, tools jaringan (ping, ipconfig, nslookup, tracert), dan aplikasi monitoring seperti Wireshark.

    
K3LH
Keselamatan, Kesehatan Kerja, dan Lingkungan Hidup. Matikan & cabut listrik sebelum membongkar, pakai gelang antistatik, rapikan kabel agar tidak membuat tersandung, dan buang limbah elektronik pada tempatnya.
